WebSocket + TLS 1.3 浏览器演示

与命令行 wss_client 使用相同协议：文本回显 + 二进制文件分片（FILE_START / QUERY / CHUNK）。 请先启动 wss_server，并在本机信任自签名证书（见下方说明）。
注意：若服务端开启 0-RTT 实验（enable_0rtt=1），浏览器无法发送 X-Nonce 头，连接会失败（日志：Missing X-Nonce，页面 code 1006）。浏览器演示请保持配置中 enable_0rtt=0。

自签名证书：若连接失败，请先在新标签打开 https://主机:端口 ，在浏览器中选择“继续访问/高级 → 继续”，再回到本页点「连接」。

页面日志通过 POST /__wss_browser_log 写入服务端 log/wss_browser.log。不要把「HTTP 日志」填成 WSS 的 TLS 端口（如 8443）：明文 HTTP 打到 TLS 监听会导致首条连接握手失败。从 http://127.0.0.1:8080 打开本页时会自动用同源 POST（8080），无需改地址。
